# odoo-hackathon-2026
Project submission for Odoo x Make-A-Ton 9.0 Kochi Hackathon 2026

## Repository Structure

- [`backend/`](./backend): Modular Subscription Management backend built with Node.js, Express, TypeScript, and Knex.js. Features dual-database compatibility (Supabase PostgreSQL / Local MySQL) and full adherence to Frontend ↔ Backend API Contract v0.1.

## Quick Start (Backend)

```bash
cd backend
npm install
npm run migrate
npm run seed
npm run dev
```

For full setup instructions, database switching details, and API documentation, see [`backend/README.md`](./backend/README.md).
